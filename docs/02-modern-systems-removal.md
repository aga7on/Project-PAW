# 02 — План удаления современных систем

Цель: убрать электричество, водопровод, автомобили, патронный огнестрел, радио/ТВ
и современный лут, не сломав выживание и ремесло.

Три слоя, в порядке применения:

| Слой | Инструмент | Что решает | Риск | Обратимость |
|---|---|---|---|---|
| 1. Песочница | Пресет `SandboxVars` | Свет, вода, генераторы, машины, лут-факторы | Низкий | Мгновенная |
| 2. Скрипты | `media/scripts/**/*.txt` | Предметы, рецепты, профессии, трейты | Средний | Пересборкой |
| 3. Lua | `media/lua/{server,shared,client}` | Системы, у которых нет скриптового рычага | Высокий | Пересборкой |

**Правило:** если задачу решает песочница — решаем песочницей. Код пишем только там,
где без него нельзя.

---

## 0. Проверенный механизм удаления предметов

В движке есть штатный флаг **`Obsolete = true`** в блоке предмета:

```
module Base
{
    item Pistol
    {
        Obsolete = true,
    }
}
```

Проверено по байткоду `zombie.scripting.objects.Item`: парсер читает ключ `OBSOLETE`,
поле `obsolete` используется в `WorldDictionary`, `RecipeManager`, `IsoGridSquare`
и `ScriptBucket`. То есть предмет исчезает из словаря мира, из рецептов и с клеток.

Это лучше, чем «оставить предмет, но убрать из лута»: не остаётся висячих ссылок
в рецептах и распределениях.

> **Не проверено на живом запуске.** Первый практический шаг — тест: объявить
> `Obsolete = true` для одного безопасного предмета (например `Base.Pistol`), запустить
> игру и убедиться, что предмет не спавнится и не появляется в меню отладки.
> До этого теста все дальнейшие шаги считаются планом, а не фактом.

## 1. Электричество

### 1.1 Сеть

| Параметр | Значение | Смысл |
|---|---|---|
| `ElecShut` | `1` | «Instant» — свет выключается сразу (проверено по `Sandbox.json`: `option1 = Instant`) |
| `AlarmDecay` | `1` | Батарейки сигнализаций садятся сразу |
| `GeneratorSpawning` | `1` | «None» — генераторы не спавнятся |

Действие: создать пресет песочницы `ProjectPAW` на основе `Apocalypse.lua` с этими
значениями. Файл кладётся в `media/lua/shared/Sandbox/ProjectPAW.lua`.

### 1.2 Генераторы

- `Base.Generator`, `Base.Generator_Yellow` — пометить `Obsolete = true`.
- `MOGenerator.lua` (map object) — генераторы, расставленные по карте, заменяются
  предметом `Base.Generator`. Если предмет стал obsolete, объект надо убрать из карты
  или заменить на декорацию.
- `GeneratorFuelConsumption`, `AllowExteriorGenerator`, `GeneratorTileRange` — становятся
  неактуальны, трогать не нужно.

### 1.3 Батарейки и потребители

|---|---|

| Телевизоры (`TvAntique`, `TvBlack`, `TvWideScreen`) | Удалить |
| Будильники (`AlarmClock2`) | Удалить (петухи, колокол) |
| Прочее (детекторы, камеры, CD-плеер) | Удалить |

`Base.Battery` — `Obsolete = true`. Рецепты `RemoveBattery`, `InsertBattery` — удалить
вместе с ними (см. 1.4).

### 1.5 Навык и профессия

- `Electrician` (профессия, `Electricity=5`) — удалить.
- Навык `Electricity` (`Perks.Electricity`) — удалить из UI и книг навыков

> Осторожно: `Perks.Electricity` используется в `XpUpdate.lua` (строки 263, 370) для

### 1.6 Объекты мира

- `MOLampOnPillar.lua` — фонари на столбах. Оставить как объекты, но без питания

**Проверка:** новый мир, ночь, зайти в дом — свет не горит, выключатели не работают,
генераторов нет в луте, батареек нет, пункта «Электрика» в меню нет.

## 2. Вода

| Параметр | Значение | Смысл |
|---|---|---|
| `WaterShut` | `1` | Мгновенное отключение водопровода |

- Краны, души, туалеты перестают быть бесконечным источником воды.
- Остаются: колодцы, дождевые бочки (`MORainCollectorBarrel`), реки, озёра, дождь.
- `Base.BucketForged`, бочки, фляги — оставить, это ядро быта.

**Риск:** если на карте мало колодцев, выживание станет невыносимым. Нужно проверить
плотность колодцев на выбранной карте до фиксации значения. Возможная компенсация:
`WaterShut=2` (14–30 дней) как «мягкий» вариант на переходный период.

## 3. Транспорт

### 3.1 Движение

| Параметр | Значение | Смысл |
|---|---|---|
| `EnableVehicles` | `false` | Машины не спавнятся (проверено: опция есть в `SandboxOptions` и переводах) |

Важно: опция применяется **при создании мира**. Менять её на существующем сохранении
бессмысленно — машины уже в мире.

### 3.2 Мусор

Даже с `EnableVehicles=false` в мире остаются:

- 84 сгоревших/разбитых машины (`burntAndSmashedVehicles`) — **оставить как декорации**;
- запчасти в луте — убрать через распределения;
- бензоколонки — оставить как объекты, но без топлива;
- сигнализации — отключить (`SirenEffectsZombies` не трогать, это про сирены).

### 3.3 Предметы и лут

- 105 предметов категории `VehicleMaintenance` — `Obsolete = true`.
- `MechanicsLootNew = 0` — убрать запчасти из лута.
- `VehicleDistributions` (GloveBox, TrunkStandard, TrunkHeavy, TrunkSports) — очистить
  таблицы: убрать шины, пиво, журналы, трофеи.
- `Base.HobbyHorse` — оставить как курьёз или удалить; на транспорт не влияет.

### 3.4 Профессия и навык

- `base:mechanics` (профессия, `Mechanics=4`) — удалить.
- Трейты `base:mechanics`, `base:mechanics2`, `base:speeddemon`, `base:sundaydriver` —
  удалить.
- Навык `Mechanics` — удалить из UI, книг и проверок. **Проверить**, не завязан ли

**Проверка:** новый мир — машин нет вообще; в гаражах нет шин и канистр; в меню
создания персонажа нет «Механика» и «Водителя».

## 9. Порядок работ и проверки

| Шаг | Работа | Проверка |
|---|---|---|
| 1 | Тест `Obsolete = true` на одном предмете | Предмет исчез из мира и рецептов |
| 2 | Пресет песочницы | Новый мир: нет света, воды, машин, генераторов |
| 3 | Удаление огнестрела и патронов | В луте нет ни одного патрона |
| 4 | Удаление электрики и электроники | Нет батареек, приборов, навыка |
| 5 | Удаление запчастей и лута машин | В гаражах пусто |
| 6 | Профессии и трейты | В меню создания нет удалённых |
| 7 | Радио/ТВ/медиа | Нет приёмников и кассет |
| 8 | Баланс еды без холодильника | Еда не гниёт за один день и не лежит вечно |

Каждый шаг — отдельный коммит и отдельный тестовый мир, чтобы можно было откатить
ровно один слой.

## 10. Ограничения, которые надо признать

1. **`Obsolete = true` не тестирован в игре.** Всё остальное построено на нём.
2. **Удаление предмета не удаляет его из старых сохранений.** Тестировать только
   на новых мирах.
3. **Модели, текстуры и звуки остаются в файлах игры.** Удаление контента в скриптах
   не уменьшает размер игры и не убирает ассеты — только логику и лут.
4. **Карта не чистится скриптами.** Современные дома, машины на улицах, бензоколонки —
   это геометрия карты. Скрипты их не уберут.
5. **`LootItemRemovalList` — не глобальный фильтр.** Это частая ошибка в гайдах;
   в B42 он работает только для собирательства.
